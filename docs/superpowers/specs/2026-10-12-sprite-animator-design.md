# 序列帧交叉修复与动画播放器（Sprite Animator）设计规范

## 1. 概述与目标

### 1.1 背景
在 2D 动作游戏美术制作与图像生成（如 AI 生图、像素切片）中，序列帧动作图（Sprite Sheet）经常因为角色动作幅度大、武器伸展过长、技能光效扩散等原因，导致相邻动作帧发生**空间重叠与穿插交叉**。传统固定等宽网格切片工具无法处理这种非均匀、存在交叉的精灵表，导致切出的帧带有相邻动作的残损像素，或者播放时产生严重位移抖动。

### 1.2 目标
构建一个**零依赖、开箱即用的纯前端单页 Web 应用（HTML5 + Canvas）**，提供完整的：
1. **透明/非透明序列帧大图导入**（支持一键抠除非透明背景）；
2. **智能自动初选框与自由矩形框选**；
3. **交叉区域专属修整**（橡皮擦擦除侵入像素、多边形/套索精确分离、容差魔棒）；
4. **帧位置与锚点对齐**（十字基准线、地面参考线、键盘 1px 微调、洋葱皮残影）；
5. **实时动画流畅播放**（1~60 FPS、单步调试、循环/单次/乒乓模式）；
6. **多格式导出**（独立透明 PNG 序列 Zip、重新排版规整无交叉 Sprite Sheet、GIF 动图）。

## 2. 系统架构与界面设计

### 2.1 整体布局规划
采用现代化深色专业工作台布局（Dark Pro Theme）：

```
+-----------------------------------------------------------------------------------------+
| [顶栏] 文件操作 (导入/导出Zip/导出精灵表/导出GIF) | 工具切换 (选框/橡皮/套索/魔棒) | 视图缩放   |
+------------------------------------------------------------+----------------------------+
|                                                            | [右上: 帧管理与对齐编辑]    |
|                                                            | - 帧列表序列 (拖拽排序)     |
|                   [中央: 大图编辑工作区]                     | - 锚点对齐 (十字线/地面线)  |
|               (支持平移/缩放/框选/擦除交叉像素)              | - 键盘微调 X/Y 偏移        |
|                                                            | - 洋葱皮残影开关           |
|                                                            +----------------------------+
|                                                            | [右下: 实时动画播放器]     |
|                                                            | - 播放视口 (带地面网格)    |
|                                                            | - 播放/暂停/单步调试       |
|                                                            | - FPS 调节 (1~60)          |
+------------------------------------------------------------+----------------------------+
```

### 2.2 核心模块交互规范

#### 模块一：图像导入与预处理
- 支持点击导入或拖拽上传 PNG/JPG 图像。
- **自动透明处理**：若导入图带有纯色背景（如纯白、纯黑或绿幕），提供“一键魔棒抠除背景”功能，可调节容差（Tolerance），将其转换为带有 Alpha 通道的透明图。

#### 模块二：交叉修复与选框编辑工作区
- **智能自动识别**：基于像素 Alpha 通道连通区域算法（Connected Component Labeling），一键自动分析出所有独立角色的包围盒，生成候选选框。
- **自由选框模式（Box Select）**：
  - 用户可在画布上自由拖拽创建新矩形框、调整边界大小、移动位置。
  - 允许选框之间相互重叠。
- **交叉消除橡皮擦（Overlap Eraser）**：
  - 当 Frame A 的边界覆盖到了 Frame B 的武器或披风时，选中 Frame A 进入“精细编辑”模式；
  - 提供橡皮擦笔刷（可调粗细），直接抹除进入本帧视野内的相邻帧残留像素，生成该帧专属的独立透明图层，彻底解决“交集”问题。
- **多边形/套索扣选（Polygon Lasso）**：
  - 支持多边形点击圈出精准边界，将多边形外部的穿插像素直接裁除。

#### 模块三：帧序列管理与位置锚点对齐
- **帧列表管理**：以缩略图形式展示当前所有已识别动作帧，支持拖拽调整播放顺序、复制帧、删除帧。
- **位置对齐（Pivot / Alignment）**：
  - 每个动作帧提供可移动的锚点（Pivot Point，默认处于角色脚底中心）；
  - 提供参考十字线与地面接触线；
  - 支持快捷九宫格对齐（底部中心、绝对中心等）；
  - 支持使用键盘方向键（↑ ↓ ← →）以 1 像素为单位精确微调该帧在播放器中的渲染位置，彻底消除动作播放时的浮空或抖动。
- **洋葱皮残影（Onion Skinning）**：
  - 勾选后，在对齐视图中半透明（30% 透明度）叠加显示前一帧或后一帧的剪影，方便肉眼比对两个连续动作的重心与地面接触点。

#### 模块四：实时动画播放器
- **播放器视口**：以中心锚点对齐方式渲染当前帧，带有棋盘格透明背景和地面参考水平线。
- **控制控件**：
  - 播放 / 暂停切换（支持空格键快捷键）；
  - 上一帧 / 下一帧步进（支持键盘左右箭头调试）；
  - 帧率滑块：支持 1 ~ 60 FPS 无级调节；
  - 播放模式：循环播放（Loop）、单次播放（Once）、往返乒乓（Ping-pong）。

#### 模块五：成果导出
- **导出独立 PNG 压缩包（Zip）**：将经过交叉修复与修边后的所有单帧分别导出为透明 PNG（`frame_01.png`, `frame_02.png` ...），并通过内联 JSZip 一键打包下载。
- **导出重新排版精灵表（New Clean Sprite Sheet）**：将所有修复后的独立动作帧按照统一的大间距、整齐网格重新排版合成一张崭新、绝无交叉的超清透明精灵表大图。
- **导出 GIF 动图**：直接将播放器渲染结果合成为带透明/自定背景的流畅 GIF 动图，方便直接在聊天工具或网页中预览分享。

## 3. 技术栈与实现方案

1. **宿主模式**：单文件 HTML 应用（`index.html`），可单机离线运行。
2. **图形核心**：HTML5 Canvas 2D Context + ImageData 像素缓冲处理。
3. **第三方内联/CDN 库**（离线安全容错，嵌入轻量压缩库）：
   - `jszip.min.js`：前端零依赖生成 Zip 文件；
   - 轻量 GIF 编码模块：前端纯 JS 编码生成 GIF。
4. **性能保障**：
   - 使用离屏 Canvas（Offscreen Canvas）缓存每一帧的切片与擦除蒙版；
   - 视图缩放与平移采用矩阵变换，避免主图反复重绘造成的卡顿。

## 4. 验证与测试标准

1. **交叉修复验证**：导入之前有交叉重叠的武将精灵图，使用橡皮擦工具成功抹除第9帧与第10帧穿插的长枪像素，两帧独立分离。
2. **位置对齐验证**：通过锚点与地面参考线微调每一帧的重心，消除播放时由于图幅尺寸不同导致的重心抖动。
3. **播放流畅度验证**：在 12 FPS ~ 30 FPS 下能流畅循环播放，无卡顿和撕裂。
4. **导出完整性验证**：导出的 Zip 压缩包包含正确的单帧透明 PNG，且能正常解压查看；导出的新精灵表无任何元素重叠。
